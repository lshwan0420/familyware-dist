# 패밀리웨어 — 배포

**패밀리웨어**(가족용 웹앱)의 버전별 변경 내용을 공개하는 저장소입니다.
소스 코드는 비공개 저장소에 있습니다.

## 변경 내용

[릴리즈 목록](../../releases)에서 버전별로 무엇이 바뀌었는지 볼 수 있습니다. 최신 버전은 [여기](../../releases/latest)입니다.

## 이 앱은

가족끼리 쓰는 작은 웹앱입니다. 설치 파일 없이 휴대폰·PC 브라우저로 쓰고, 홈 화면에 추가하면 앱처럼 열립니다.

- **소식·사진 앨범** — 가족 소식과 사진 나누기
- **가족 캘린더** — 일정, 생일·기념일(음력), 공휴일
- **가족 채팅** — 실시간 대화
- **요청·투표** — 용돈·구매·허락 요청, 가족 투표
- **가족 구성원** — 구성원·관계·연락처, 초대 코드로 가입

접속 주소와 초대 코드는 가족 관리자에게 받으세요. 이 저장소에는 접속 주소를 적지 않습니다.
